## 字幕、图标与代码库

| 场景 | 参考与实现 |
|---|---|
| 口播关键词逐个变色 | 把说到的词单独点亮，适合数字和专有名词。先校对中文分词、字级时间和字体，再用 Remotion 渲染。部分组织须另购 Remotion 许可。 [Remotion TikTok 字幕](https://github.com/remotion-dev/template-tiktok) |
| 公式变形、实轴与零点定位 | 坐标、函数和公式可以跟着真实数值变化。选示例、改参数、用 Python 渲染成短镜头。框架采用 MIT 许可。 [Manim 数学示例](https://github.com/ManimCommunity/manim) |
| 工具调用、检索、核验等小图标 | 给搜索、文件、工具调用各配一个会动的小图标。用 React 组件控制触发时间，再输出为叠加层。仓库标注 MIT。 [Lucide Animated 动态图标](https://github.com/pqoqubbw/icons) |
| 模型等待、连接或加载 | 适合“模型正在思考”的等待镜头。下载 SVG，在浏览器中运行动画，渲染成剪辑素材。仓库标注 MIT。 [SVG Spinners 等待动效](https://github.com/n3r4zzurr0/svg-spinners) |
| 两张图或两个镜头之间的过渡 | 用两张画面或两段视频控制转场进度。需要支持 GLSL 的渲染器，许可按各个转场文件头查看。 [GL Transitions 转场库](https://github.com/gl-transitions/gl-transitions) |

模板可用性与商用范围分开核对。采用原素材时看包内代码、字体、音效和音乐各自的许可；替换成本期有权使用的素材。自制透明层需导出支持 Alpha 的格式，普通 MP4 可直接用作独立镜头。
