# 实剪时间表：从一个问题到一页日历

下列镜头取自《黎曼猜想》科技风弹缩定稿。案例小片从定稿 00:10.40 起，到 00:15.80 止。表中时间是**案例内时间**，按 30 fps 计算。用这段学人物、图和声的接力关系，做新片时重新听当期素材。[看 5.4 秒有声案例](https://github.com/wuhetu619-crypto/-/blob/main/examples/riemann/host-calendar-return.mp4)

| 案例时间 | 口播与注意力 | 可观察的剪辑决定 |
|---|---|---|
| 0.00–1.60 秒 | “它到底在问什么呢？” | 全屏真人配普通字幕。观众需要看提问者的表情。 |
| 1.60–2.00 秒 | 从提问衔接到“打开手机日历” | 同一人像向左缩为圆窗；气流声随缩入，避开脸部运动路径，让右侧日历在落位附近显现。 |
| 2.00–4.07 秒 | 视线跟着“日历”走 | 右边给完整的日历，左边保留正在说话的主播；留出一眼读懂月份和日期的时间。 |
| 4.07–4.43 秒 | “你就能看到第一步” | 日历退出，左侧圆窗连续弹回全屏，在落稳处给短落点声。 |
| 4.43–5.40 秒 | 句尾 | 回到表情和普通字幕，给下一个观察任务留出干净的切点。 |

## 在同一条片里换手法

| 实录触发 | 借用的动作 | 决定何时结束 |
|---|---|---|
| “悬赏 100 万美元” | 按本 skill 的新版开场规则，先露脸、前三帧留白；金额在脸侧出现，命中一次。 | 金额已读清就退，下一句仍能看到说话的人。 |
| “2、3、5、7” | 在同一页日历上按念数顺序画四个圈，各响一次。 | 四圈画完保持，不能让四个圈从头循环。 |
| “一直接到一万亿格” | 格数加速，配逐渐上扬的“呜”声；读到量级时落在准确数值。 | 反问“一共得圈多少个圈”时停滚，下一句可直接露脸。 |
| “公布了他和 Claude 的答案” | 人物屈肘单独举手，Claude 标志独立轻跳一次。 | 各自动作落稳；第二处出现同一角色也检查手臂连接和标志轮廓。 |
| “验算……题目本身也要验” | 左右分区，讲到哪项点亮哪项；提出“万一”时回到真人。 | 两项都已说明时结束勾选。 |
| “还想举手问一句” | 先呈现坐着的观众，在“举手”处才抬手。 | 最后一句切回主播，让他的眼神和语气承担收尾。 |

另一类 AI 工具实测可以做环绕图标。词里讲到多 Agent 协作时，图标围绕本人沿有前后遮挡的椭圆轨迹运动，避开脸和字幕。前作中的 16 个图标是那一期的主题数量；新片按实际工具数取舍。
